# 📌 Employee Management System

A frontend-based Employee Management System that allows an Admin to create and assign tasks to employees.  
Employees can view their assigned tasks and track their status (New, Completed, Pending).  
The project uses LocalStorage to persist data without a backend.

---

## 🚀 Features

### 👨‍💼 Admin Dashboard
- Create and assign tasks
- View employee details
- Track task status:
  - 🆕 New Tasks
  - ⏳ Pending Tasks
  - ✅ Completed Tasks

### 👨‍💻 Employee Dashboard
- View assigned tasks
- Check task status
- Dynamic task updates

### 💾 Data Storage
- Employee data stored in JSON format
- Task data saved in LocalStorage
- Data persists after page refresh
